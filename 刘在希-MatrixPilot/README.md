## 处理范围与口径

固定翼控制固件的采集、姿态与定位、飞行状态、航线、控制输出、通信，以及条件外设、仿真和配套工具。

以所记录源码快照中的有效行为恢复需求；默认功能与条件启用功能分别说明。文字、算法及图示为需求层面的系统行为表达，保留影响行为的条件、阈值、单位、时序和异常处理。目录页码按本次 PDF 的物理页序排列。
