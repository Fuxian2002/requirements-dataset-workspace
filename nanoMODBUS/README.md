# nanoMODBUS

- 项目类型：面向嵌入式与微控制器的紧凑型 Modbus RTU/TCP 协议栈库（C 语言，可移植中间件：无 `main()`、无硬件驱动、无外设控制、无动态内存分配）
- 上游仓库：https://github.com/debevv/nanoMODBUS
- 锚定提交：`91d6782930ee263bc760f27b0cbc5b82773c5f0d`（2026-02-01，tag `v1.23.0`，与 master HEAD 为同一提交）；仓库无版本宏、无 `VERSION` 文件，版本仅由 git tag 承载
- 许可证：MIT（仓库根 `LICENSE`，Copyright (c) 2022 Valerio De Benedetto (@debevv)）
- 逆向产出：《nanoMODBUS 软件需求规格说明书（竣工需求·逆向）》md / docx / pdf 三件套 + 《引用核验报告》 + 《选型表符合性核验》
- 需求规模：77 个需求块（`NMB-FREQ` 48、`NMB-IREQ` 15、`NMB-PREQ` 7、`NMB-SREQ` 7），916 条证据引用、2 张图、25 张表，文档编号 `REQ-NMB-ASB-001`
- 处理范围：档 2——根目录 `nanomodbus.c` / `nanomodbus.h`（3,024 行）+ `tests/`（2,035 行），共 7 文件 / 5,059 行；`examples/` 不在范围内，仅在边界处交代
- 对外契约面：29 个公开函数 + 12 个服务器回调 + 8 个库错误码 + 4 个 Modbus 异常；功能码 12 个（01、02、03、04、05、06、15、16、20、21、23、43）
- 产出日期：2026-10-19（文档与入库同日）
- 方法：大模型辅助的源码静态逆向，按星载软件需求规格说明书格式组织；每条需求附 `文件:行号` 证据
