# 嵌入式项目需求处理共享仓库

本仓库用于集中保存学生对开源嵌入式项目进行需求抽取、SpaceRDL 形式化和追踪分析的成果。

## 当前项目

- `SMART-QSO/`：SMART-QSO 1U CubeSat 项目的需求处理结果。

## 最简单的协作方式

1. 从 `main` 新建自己的分支，分支名建议为 `姓名-项目名`。
2. 在对应项目目录中修改或补充文件。
3. 提交并推送自己的分支。
4. 在 GitHub 上创建 Pull Request，经检查后合并到 `main`。

请不要直接向 `main` 推送，也不要删除或覆盖其他同学尚未合并的成果。

## 每个项目建议包含

- `SOURCE.md`：源项目地址、提交版本、许可证和处理范围；
- `requirements.md`：抽取和规范化后的需求；
- `resources.md`：控制器、设备、数据、算法和协议资源；
- `statements.md`：需求到 SpaceRDL 语句的映射；
- `code.rdl`：SpaceRDL 草案；
- `traceability.md`：来源、需求、语句和代码之间的追踪关系；
- `issues.md`：冲突、缺失、歧义和待确认项。

不强制所有项目具有完全相同的文件，但必须保留源项目地址和准确提交版本。

## 注意事项

- 禁止提交 API Key、密码、访问令牌、个人隐私或未授权数据。
- 第三方源码和文档受其原始许可证约束；优先保存来源链接、提交 SHA 和定位信息，不要无条件复制整个原项目。
- 自动生成结果必须标明模型、提示词版本、验证工具和人工修改情况；无法验证的内容应标记为候选或待确认。
