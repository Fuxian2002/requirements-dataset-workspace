# ESCape32

- 项目类型：面向 32 位 MCU 的无刷电机电子调速器（ESC）固件（C 语言，裸机，多 MCU 家族）
- 上游仓库：https://github.com/neoxic/ESCape32
- 锚定提交：`1d718c143380c3eb7e6581478990e1496632e5b8`（2026-10-02，tag `rel17`，与 master 最新提交为同一提交）；固件版本 `REVISION 17` / `REVPATCH 3`（`src/main.c:20-21`），配置标识 `cfgdata.id = 0x32ea`（`src/main.c:24`）
- 许可证：GPL-3.0（仓库根 `LICENSE` 与各源文件头）
- 逆向产出：《ESCape32 软件需求规格说明书（竣工需求·逆向）》md / docx / pdf 三件套 + 《引用核验报告》
- 需求规模：188 个需求块（`ESC-FREQ` 138、`ESC-IREQ` 20、`ESC-PREQ` 16、`ESC-SREQ` 14），3,388 条证据引用、19 张图、32 张表，文档编号 `REQ-ESC32-ASB-001`
- 处理范围：档 2——`src/` + `mcu/`，47 文件 / 6,642 行；`boot/` 不在范围内，仅在边界处交代
- 目标器件：7 个 MCU 家族（STM32G431 / STM32G071 / STM32L431 / STM32F051 / AT32F421 / GD32F350 / GD32E230）、44 个固件 target
- 产出日期：2026-10-18（文档）/ 2026-10-19（入库）
- 方法：大模型辅助的源码静态逆向，按星载软件需求规格说明书格式组织；每条需求附 `文件:行号` 证据
