# uCNC（内核版）

- 项目类型：面向微控制器的通用数控机床运动控制固件（C 语言，裸机，无 RTOS）
- 上游仓库：https://github.com/Paciente8159/uCNC（核心）、https://github.com/Paciente8159/uCNC-modules（外部模块）
- 锚定提交：核心 `4f4e5809516dae7008bd705b745096be923ea99c`（2026-09-02，tag `v1.17.0`）；外部模块 `660630760af6e7d86166c7ea782c79030c74adfd`（2026-09-03）
- 许可证：GPL-3.0（仓库根 `LICENSE`）
- 逆向产出：《µCNC 运动控制内核软件需求规格说明书（竣工需求·逆向）》md / docx / pdf 三件套 + 《交付前终检报告》
- 需求规模：191 个需求块（`UC-FREQ<功能域>-<序号>`），文档编号 `REQ-UCNC-001`；2,283 条 `文件:行号` 证据引用
- 处理范围：**内核版**——从 G 代码字节流到步进脉冲的完整链路（解析、表达式、模态、运动控制、规划与块缓冲、插补、归零、探测、高度图、运动学变换、G5/G7/G28.1/G33/G96），以及系统调度、状态机与并发原语。主轴/冷却/刀具、机器 IO、限位与安全、Grbl 协议、设置与持久化、HAL 与板级支持、文件系统与网络等不在本文范围（详见文档 §1.3）。
- 产出日期：2026-10-18（文档）/ 2026-10-19（入库）
- 方法：大模型辅助的源码静态逆向，按《太搜文档》格式组织；每条需求附 `文件:行号` 证据

> 说明：同一工作区另有覆盖全量范围的《µCNC 逆向需求规格说明书》，**未**收录在本目录。本目录只对应内核版，两者的需求标识与章节划分不同，请勿混用。
